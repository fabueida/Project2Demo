# Project2 — Accessible React Contact Book

A responsive React contact book built for Project 2. It uses Vite, JSX, props, React state/hooks, controlled form inputs, events, list keys, conditional rendering, and JavaScript array methods.

## Features
- Add contacts with required Name and Email plus optional Phone
- Controlled form inputs and validation
- List all contacts using `map()` and stable contact IDs
- Delete individual contacts using `filter()`
- Controlled Search/Filter by name or email
- Clear empty states for no contacts and no search matches
- Responsive desktop/mobile layout
- Accessibility: semantic landmarks/headings, labels, visible focus, skip link, status announcements, descriptive button labels, reduced-motion and high-contrast support
- No backend; data remains in memory for the current session as required

## Run the project

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Production build

```bash
npm run build
```
